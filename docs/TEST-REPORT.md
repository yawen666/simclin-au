# SimClin AU 1.0 测试报告

测试日期：2026-08-04
测试范围：本地可运行版本、模拟 AI 闭环、真实 DeepSeek 闭环、桌面与移动端 UI、角色权限与安全边界。

## 结论

SimClin AU 1.0 已完成本地闭环并通过交付前回归。学生可以从五个预置病例中选择一个，进行流式英文病史采集，提交后获得基于逐条证据的反馈；教师可以管理病例、评分表、发布状态、成绩证据、人工改分和教学洞察。

本轮消息生命周期补充验证：AI 响应失败或中断的学生消息继续以 `failed` 状态保留在数据库供审计，但不会进入后续 Planner/Actor 上下文、Evaluator 输入、结果 transcript 或练习问题计数；前端会撤回未成功的临时问答并提示重新提问。Playwright 同步改为按后台评价契约轮询结果，并验证学生从 Practice history 打开已生成反馈。

## 真实 DeepSeek 验证

使用 `deepseek-v4-pro`，服务端保留 API key，浏览器不接触 key。

- Real smoke：认证、流式标准化病人响应、评估、结构化评分全链路通过。
- 五病例 real regression：胸痛、呼吸困难、餐后烧灼痛、雷击样头痛、口渴多尿五个病例均完成真实 actor + evaluator 调用并返回 7 个评分域。该回归按单个聚焦问题验证模型链路，因此分数偏低是预期现象，不代表病例教学目标的完整表现。
- 回归过程中发现并修复了 DeepSeek 超时错误被二次异常遮蔽的问题；现在会安全处理非字符串错误码，评估超时边界提高到 90 秒，并返回可识别的 `AI_TIMEOUT`。

## 临床内容与安全边界

病例为合成教学草稿，主要覆盖内科场景；内容参考澳洲公开临床教育资料组织，但尚未经过医学院课程委员会、临床专家或伦理/隐私治理的正式签字。当前版本只做病史采集，不生成临床总结、鉴别诊断或管理计划，也不面向真实患者使用。内置账号和 JWT 仅用于本地演示，不能视为生产级身份认证。

## 已知限制与下一步

- 教师 Preview 当前是结构化病例预览，不会额外发起一次 AI 试问诊。
- 评分结果支持教师复核和审计改分，但尚未包含正式课程成绩册、SSO、真实学生账号或多租户部署。
- 发布前仍应由澳洲医学院教师和临床专家完成病例、评分表、红旗问题和反馈文案的治理审核。
- `server/.env` 中的开发 key 只用于本地测试；在共享代码、部署或继续开发前应立即轮换。

## 本地复现

在项目根目录执行：

```bash
npm run build
npm run test
npm run test:e2e
npm --prefix server run test:smoke:real
npm --prefix server run test:regression:real
```

Playwright 使用隔离临时 SQLite 数据库；真实测试使用 `server/.env` 中的 DeepSeek 配置。
